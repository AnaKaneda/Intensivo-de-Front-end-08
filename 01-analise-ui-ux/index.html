Análise de UI e UX - YouTube

Aspectos de UI

  • Ícones fáceis de identificar.
  • Layout organizado.
  • Miniaturas destacadas dos vídeos.
  • Cores e elementos visuais padronizados.

Aspectos de UX

  • Pesquisa fácil de utilizar.
  • Recomendações de vídeos para o usuário.
  • Navegação simples entre as páginas.
  • Fácil acesso ao histórico e às inscrições.
